# Kev-4B + Flash 同场对照报告

日期：2026-09-30。负责人：lqj。状态：两轮 64/64 次尝试完成，独立账本复算通过，待非作者评审。

## 结论

**本次固定 Kev-4B 替换没有达到“更快且相近准确度”的目标。** 纯 Flash 通过 26/32（81.25%），Kev+Flash 通过 14/32（43.75%），相差 37.5 个百分点。协作组全量累计耗时多 17.8%；即使只比较双方都成功的 14 对任务，协作组仍多耗时 67.4%。

这是对当前模型、输入适配与部署组合的负结果，不是官方 Jev 成绩，也不能推出所有 Kev 或所有较大决策模型都无效。实验仍有意义：**减少大模型请求不自动带来端到端提速，动作选择和停止判断的质量同样关键。**

## 分工与条件

- **A：纯 DeepSeek Flash。** 一次返回动作、目标及必要文本，不人为拆成多次大模型请求。
- **B：Kev-4B + 同一 Flash。** Kev 从环境和框架提供的候选中选择动作、目标及停止状态；Flash 生成字段文本，保留作者原有下拉值 helper。候选不是 Flash 预生成的答案。框架执行，独立验收，不以 DONE 代替通过。
- 决策模型为旧版 `jaredpalmer/kev-4b@qwen3`，Qwen3-4B-Base 底座，实际约 **4.024B** 参数。不是当前 Qwen3.5 主版本，也不是 2B。固定源码、adapter、底座及依赖见[环境验收](kev-environment-readiness-20260930.md)。
- Windows 浏览器沿用此前实验的 Chromium headless-shell 1243；Kev 在独立 WSL2 Ubuntu 24.04、RTX 5070 Ti 16GB 上运行，BF16 / SDPA，使用作者原生加载与评分服务，无 CPU 回退、无日期规则。此 attention-only 模型不适用 hybrid 专用优化内核；不能等同于上一轮 Decider 缺优化内核的情况。
- 沿用社区浏览器权重作者 Suite A 的原 **16 题 × 2 轮**、原提示、状态压缩/候选分块、工具和验收。只替换 B 的决策模型，不加载 Laya/Decider，不做训练、提示调优或候选删减。A/B 交错，第二轮反转先后顺序，每次独立浏览器上下文。
- Flash 官方 `deepseek-flash`，显式非思考模式，temperature=0、top_p=1、max_tokens=1024、JSON 输出；浏览器与 Flash 使用 7890 代理，本地服务直连。沿用 20 条动作历史、120 次框架决策、180 秒协作式时限、25 秒 HTTP 超时、原重试，总上限 237 次 Flash HTTP。撤销等额外工具操作单独计数，不受“20 条历史”数字掩盖。
- 正式任务时间为 **18:54–19:05（Asia/Shanghai）**。加载和三次原样例预热单列；每题前清空 Kev 前缀缓存，题内保留作者默认缓存。计时中不跑工程测试，不改配置，不补跑失败项。

## 结果分析

1. **请求迁移成立，整体收益不成立。** Flash 请求减少 69.1%，但 B 另有 246 次 Kev 请求；模型调用时间仅减少 15.506 秒，工具时间增加 60.767 秒。工具次数增加 72.6%，吞没了模型端节省。
2. **有可复核的重复操作。** `books-travel` 两轮 B 均执行 20 次工具，在分类页、书籍页和其他分类间往返，最后回到正确分类；A 各一次工具即完成。`web-search` 第二轮 B 多次重复填写和提交，耗时 41.362 秒，A 为 11.534 秒。它们最终通过，但并不高效。
3. **提前停止不能当加速。** Python 下载页、名言标签等任务中 B 未到达目标就输出 DONE；维基任务出现 BLOCKED。这些快结束均记失败。arXiv 任务两轮 B 均进入论文详情而非所需搜索结果，属于观察到的目标选择偏离，不能只归因于工具慢。
4. **错误和验收限制保持透明。** A 首轮复选框任务有一次 Flash `ConnectError`，没有 HTTP 状态或 token 用量，不补零、不归因于模型决策。工具 `StalePage` 尝试 A/B 为 14/9 次，均保留；B 的更多工具调用不能解释为它有更多这种错误。B 两轮复选框均被实际 checked=true 检查判失败，未沿用作者字符串误判。

## 边界与证据

- 初始观测完全一致的是 **27/32 对**，公开网站并非静态环境。仅在这 27 对中，A/B 通过 21/27、13/27；共同成功 13 对的 A/B 速度比仍为 0.586，方向没有反转。这是透明的事后敏感性检查，不替代全量主结果。
- 保留作者已过期航班日期，以及部分仅按 URL/标题/页面文字判定的弱验收。两轮只是 16 类任务的重复，不能当 32 个独立任务，也没有预设质量等价阈值。
