# Jev 式决策协作：DeepSeek Flash 完整两轮对照

实验日期：2026-09-29 23:44–23:56 Asia/Shanghai。负责人：lqj。

## 目的与结论

**验证用 Laya 承担 Jev 式动作选择、DeepSeek 承担必要生成和辅助，能否比纯 DeepSeek 更快，且保持相近的任务通过率。** 按 lqj 要求，本次只把原两组 Qwen 换成官方 `deepseek-flash`，不调整任务、提示、Laya、工具、验收、代理或重试。原 Qwen 报告和数据单独保留。

**16 个任务 × 2 组 × 2 轮，64 次尝试全部完成，0 次未启动。** 没有选择性补跑或覆盖失败。

- **通过率相同，但失败原因不同**：A 纯 Flash、B Laya+Flash 均为 **26/32（81.25%）**，每轮均为 13/16。A 的复选框任务两次在调用模型前报页面错误；B 的指定书籍任务两次选错终态。因此相同总分不能直接证明模型质量等价。
- **成功配对有提速**：24 个双方成功的同题同轮配对，A/B 累计 **265.850 / 211.509 秒**，速度比 **1.257**，耗时减少 **20.4%**；其中 19 对 B 更快、5 对 A 更快。
- **全量收益较小且轮间不稳定**：包含全部失败后，A/B 累计 **379.482 / 362.544 秒**，B 仅少 **4.5%**；第二轮全量反而是 B 更慢。不能把成功子集的 20.4% 写成全量提速。
- **远端大模型请求减少**：Flash 实际 HTTP 请求 **103 对 18，减少 82.5%**；B 另有 **163 次 Laya 请求、180 次实际前向**。全场 121 次 Flash 请求全部 HTTP 200，**没有限流退避，不需要扣除等待**。

本轮支持“成功任务可以提速、远端大模型请求显著减少”的有限结论；**尚不能证明稳定的整体提速与统计质量等价**。这不是 TypeSafe Jev 原模型的实测成绩。

## 分工与候选来源

| 环节 | A：纯 DeepSeek Flash | B：Laya+DeepSeek Flash |
| --- | --- | --- |
| 网页观测和候选 | 浏览器框架读取真实 DOM 与支持的动作集合 | 同一框架，不由大模型提前生成候选或计划 |
| 动作、目标与继续/结束决策 | Flash 一次返回操作、目标及必要文本 | Laya 直接选择操作与目标，可以选择 DONE/BLOCKED |
| 字段文本 | 合并在同一次决策响应中 | Flash 按需生成，本次 16 次请求 |
| 下拉值 | Flash 在决策中选择具体选项 | 保留作者 helper，由 Flash 辅助具体值，本次 2 次请求 |
| 工具执行及成功判定 | 框架执行，同一独立验收器评分 | 相同；DONE 本身不代表成功 |

B 保留作者的输入压缩、截断、候选分块和已启用的执行保护；未加入规划、大模型升级代选、LLM 完成检查或任务专用规则。比较的是两种完整方案，不是输入逐字相同的模型参数消融。来源为固定作者发布的 [Suite A](https://huggingface.co/cklxx/laya-browser/blob/645cf366a2ae35f1086e8c20eff48f909bb49206/code/apps/browser_suite.py)、[包装器](https://huggingface.co/cklxx/laya-browser/blob/645cf366a2ae35f1086e8c20eff48f909bb49206/code/apps/laya_browser.py)和[引擎补丁](https://huggingface.co/cklxx/laya-browser/blob/645cf366a2ae35f1086e8c20eff48f909bb49206/code/jev-ultrafast.patch)。

## 结论边界

- **相同通过率不是质量等价证明**：独立任务只有 16 个，重复两次不是 32 个独立任务；没有预先定义非劣效容忍度。A 的两次环境失败与 B 的两次书籍任务失败恰好抵消，不能因此宣布选择能力相同。
- **提速结论必须带范围**：两轮共同成功任务均有平均提速，但全量第二轮 B 更慢、全量 p95 也更高。本轮没有证据支持“整体稳定地大幅加速”。
- **仍有环境和验收限制**：24/32 对初始观测散列一致，其余存在不同或缺失；部分验收依赖 URL/标题。报告的是固定验收下的任务通过率，不是强语义准确率。航班题原定日期 2026-09-28 已过期，仍保留在分母，不据此判断模型能力。
- **研究对象不变**：这是作者浏览器方案加纯 LLM 对照的本地适配，不是原版 TypeSafe Jev 成绩，也不是对 Qwen 与 Flash 的严格跨模型排名。本轮没有改提示、候选处理或作者辅助策略来优化结果。
