# Mobile 前端重设计 — 讨论决议（2026-10-10）

状态：讨论已收敛，未动工。本文档是后续 spec/plan 的输入。

## 产品定位（历次讨论收敛）

- **口袋 work assistant**：掏出手机就能指挥电脑干活——开发、测试、信息处理、监控守候，不限于 coding。
- 手机 = 入口 + 验收台；电脑（Mac/Linux，未来全部）= 算力与执行环境。
- **LLM 配置与机器解耦**：LLM（provider/apiKey/baseUrl/model）是 app 级全局配置；机器只是运行环境，配置里没有 LLM 字段。
- **纯对话不需要机器**：无沙箱/无 gateway 时 agent loop 直接在手机上跑，只调 LLM。
- 检验标准：完整委托循环（下发 → 过程可见 → 结果验收）在手机上闭环。

## 信息架构：三层结构（微信式两层推广为三层）

```
第一层  机器列表（首页）
          卡片：名称 + 在线态(healthz 探活) + 运行中任务数
          编辑（改名/token/信任级别/沙箱类型/删除）：长按或右上菜单，不占导航层级
          新建机器："+" 按钮（defaults.json 预填机制保留）
第二层  任务列表（某机器内；纯对话任务挂在"无机器"虚拟位置）
          卡片：任务名 + 最后一条消息摘要 + 相对时间 + 状态点 + 未读徽标
          搜索（全局、跨任务内容搜索）：后置
第三层  会话页（Chat）
```

- 新任务在机器内创建，天然绑定机器（会话绑定机器已确认）。
- Chat 页不再是一级页；Sessions 页改名 **Tasks**。
- Settings 与连接配置**分家**：Settings 只留 app 级（LLM 配置、字体/主题）；连接配置全部移入机器编辑。

## 任务模型

- **多任务真并行**：同机多沙箱（每任务一个沙箱），架构上 `live`/`pumps` 已按 session 分桶，主要是 UI 与状态表达。
- **状态机**（对齐 omp）：`running（含 activity 一句话）/ waiting（等输入）/ completed / failed / aborted`；从持久化消息尾部推导（omp 同款），不新增协议。
- **未读徽标**：后台任务来消息 +1，点进清零。
- **任务标题自动生成**：首条用户消息经小模型压缩成一句话（omp task-label 同款），失败回退首条消息截断。
- **compaction**：自动压缩（runtime 已有 compaction 基础）+ Chat 页手动入口。

## 连接生命周期

- **懒连接**：进入会话页只 replay 本地历史（entries.jsonl），**不连接**；发消息时才连 gateway/建沙箱。
- 连接按任务管理（多机多任务并行连接，互不干扰）。
- 失败策略：**手动重发**（不自动重连、不静默重建）——失败显式报错，用户自己重发。

## 输入交互

- **排队注入**（微信式）：agent 忙时消息照发，显示"排队中"，turn 结束自动注入；**打断（stop）始终可用**；打断后排队消息保留。
- 移除突兀的 Steer 按钮（排队机制取代）。
- **语音输入：砍掉**。

## 消息与结果验收

- 工具卡片：默认折叠（命令 + 一行结论），点开看全文；diff/git 输出 +/- 着色。
- agent 端约定（prompt 层）：测试/构建结果先说结论行再贴日志。
- 图片输入：支持（相册选图发给 agent；gateway fs/upload 已有，需 uniffi + UI）。

## 安全模型

- **不做工具级权限门**：信任级别（trust_profile）在机器配置里一次性给足，运行中不询问。防事故由 sandbox/信任级别兜底。

## 通知

- 任务结束（完成/失败）时发系统通知，仅限**不在前台的任务**。
- 需要前台服务支撑熄屏场景（工程项，与通知一起排）。

## 模型配置

- **多套 LLM 配置**（多 API key/多模型），存 app 级 DataStore。
- **对话内切换模型**（runtime `set_model` 已支持 Idle 即时/运行中排队），Chat 页加切换入口。

## 明确不做 / 后置

- 砍掉：语音输入。
- 后置：全局任务搜索、iOS、公网穿透 UI、机器详情页（四层）、@机器引用、欢迎引导、系统资源监控。
- 已有决策延续：gateway 公网暴露策略未定（现阶段局域网为主）。

## 实现依赖盘点（关键路径）

1. gateway 新增 `os`（无沙箱直跑）后端类型 → 纯对话/完全信任场景。
2. mobile-core：`machine_id: Option<String>` 进 SessionState；无机器 session 跳过 gateway。
3. uniffi 新增：`setModel`、per-session 事件轮询已有、未读计数（Kotlin 层）。
4. Kotlin：三层导航重构、任务列表（摘要/状态/未读）、懒连接、排队注入 UI、通知（前台服务）。
