# Agent Team moved

The Agent Team product (`llm-harness-agent-team`, `llm-harness-agent-team-studio`,
`llm-harness-runtime-app`, and `llm-harness-runtime-app-shell`) now lives in the
standalone **[oh-my-harness/agent-team](https://github.com/oh-my-harness/agent-team)**
repository.

Use that repository for the Agent Team guide, Studio startup, Survey Guard, and
lifecycle documentation. This Runtime repository keeps only the general-purpose
runtime crates.

The previously Runtime-only live GLM Agent Team test and example are archived at
`docs/archive/runtime-v0-agent-team-live-tests/`; they are not part of the Runtime
workspace.
